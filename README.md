
# Calculadora Python

Projeto desenvolvido em Python com o objetivo de praticar
fundamentos da programação.

## Funcionalidades

- Adição
- Subtração
- Multiplicação
- Divisão
- Tratamento de erros
- Menu interativo
- Opção para continuar ou encerrar

## Tecnologias

- Python 3

## Como executar

1. Clone este repositório.
2. Abra a pasta do projeto.
3. Execute:

```bash
python calculadora.py
```

## Aprendizados

Durante o desenvolvimento, pratiquei funções,
condicionais, laços de repetição, tratamento de
exceções e organização de código.
